# BISSWERK

Demo-Website für ein deutsches Fast-Food-Lokal. Next.js, TypeScript, CSS.

## Starten

```bash
npm run dev
```

## Inhalte austauschen

- Texte, Preise, Adresse, Öffnungszeiten: `src/content/site.ts` und `src/content/menu.ts`
- Fotos: `public/images` (Pfade stehen in `menu.ts`)
- Extras, Lieferkosten und Zahlungsarten: `src/content/ordering.ts`
- Preise sind Cent-Beträge und werden als Euro angezeigt

Adresse, Telefon, E-Mail, Speisekarte und Fotos sind Platzhalter. Die Kasse ist eine Demo und schickt keine Bestellung ab.
